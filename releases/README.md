# Sideload APKs

**ArrsHubStatus-1.0.2-universal-debug.apk** — single universal debug build for phones and tablets (Pixel-safe).

## Install on Pixel

1. Open this file on the phone (GitHub → download, or copy to Google Drive and open there).
2. Allow **Install unknown apps** for Files / Drive / Chrome when Android asks.
3. Tap **Install**.

This is a normal single APK (not a Studio split deploy). After it’s on a device, **Settings → Share APK** can send that same installable file to other devices.
